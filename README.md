### 公式说明

#### 数据查找公式
```excel
=ROUND(HLOOKUP($C$2,bs!$C$1:$AB$110,MATCH(TRIM(B4),TRIM(bs!$B$1:$B$110),0),FALSE),0)
/IF(ISNUMBER(SEARCH("亿",$B$1)),100000000,IF(ISNUMBER(SEARCH("万",$B$1)),10000,1))
```

**公式解析：**
- `HLOOKUP` - 按日期横向查找数据
- `MATCH(TRIM(...),TRIM(...),0)` - 精确匹配项目名称（去除空格）
- `ROUND(...,0)` - 四舍五入取整
- `IF(ISNUMBER(SEARCH(...)))` - 根据单位自动换算（亿/万/元）

#### 占比计算
- 资产部分：`金额 / 资产总计`
- 负债部分：`金额 / 负债合计`
- 权益部分：`金额 / 所有者权益合计`
